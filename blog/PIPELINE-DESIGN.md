# 블로그 자동화 설계 v1

## 목표

AI가 소재 조사, 사진 후보 선별, 본문 초안, 사진 배치, 제휴 고지, 검수 리포트까지 만든다. 실제 경험의 진실성·개인정보·광고성·최종 게시 권한은 자동화가 넘지 않는다.

## 콘텐츠 유형

| 유형 | 입력 | AI 작업 | 게시 조건 |
|---|---|---|---|
| 실제 경험 글 | 경험 브리프, 승인 사진 | 구성·문장·사진 배치 | 경험 근거와 사진 권리 확인 |
| 트렌드 정보 글 | 네이버 트렌드, 공식 출처 | 주제 선정·리서치·이미지 제작 | 출처·사실 검수 |
| 제휴 추천 글 | 상품 근거, 제휴 링크 | 비교 기준·추천 초안·이미지 배치 | 광고 표시·링크·상품 정보 검수 |

## AI 역할 분리

| 역할 | 실행 도구 | 산출물 | 금지 |
|---|---|---|---|
| 트렌드 스카우트 | Python + NAVER DataLab/NCP API Hub | 주간 주제 후보·추이 | 검색량 절대치로 과장 |
| 에디터 | GPT 또는 Claude | 제목·목차·초안·SEO 메타 | 경험·효능·가격 환각 |
| 사진 디렉터 | GPT/Claude 비전 + ImageGen | 사진 후보·촬영/생성 프롬프트·배치표 | 개인 사진 외부 전송·무단 인물 합성 |
| 팩트 체커 | 공식 URL 대조 | 주장·출처·확인일 목록 | 출처 없는 단정 |
| 컴플라이언스 검사 | 규칙 엔진 + LLM | 게시 가능/보류 리포트 | 광고표시 누락 승인 |
| 게시 보조 | Aside 또는 브라우저 | 임시저장 원고 입력 | 운영자 승인 없는 발행 |

## 데이터 흐름

```text
네이버 트렌드 + 주제 씨앗
        ↓
주제 후보 점수화 ──→ 운영자 또는 규칙 기반 선택
        ↓
경험 브리프 + 사진 자산 목록 + 공식 근거
        ↓
본문 초안 + 사진 배치표 + 제휴 고지문
        ↓
사실성 · 사진 권리 · 광고표시 · 링크 검사
        ↓
네이버 블로그 임시저장 → 운영자 최종 승인 → 발행
```

## 2030 여성 트렌드 수집

- 대상 조건은 모바일, 여성, 연령 코드 `3`~`6`(19~39세)으로 둔다.
- 후보 키워드는 주제군별 최대 20개를 묶고, 한 요청에서 최대 5개 주제군만 비교한다.
- 결과는 상대지수이므로 같은 요청 묶음 안에서만 우선순위를 비교한다.
- 네이버 개발자센터의 Search Trend/Shopping Insight는 NCP NAVER API HUB 이관 일정이 있으므로, 새 키는 API Hub 기준으로 보관한다. 기존 개발자센터 계약을 새로 전제하지 않는다.

## 사진 정책

`assets/personal/`에는 원본 사진을 넣고 `briefs/`에는 경험 사실만 기록한다. AI는 사진을 다음 순서로 사용한다.

1. 경험과 직접 연결되는 승인 사진을 우선 사용한다.
2. 정보 설명용 빈 자리는 직접 촬영 후보 또는 AI 생성 이미지로 채운다.
3. AI 생성 이미지는 실제 사용 사진처럼 설명하지 않는다.
4. 얼굴·집 내부·위치·문서가 드러난 사진은 게시 전 비식별화 또는 제외한다.

## 쿠팡 파트너스 v1

- 첫 단계는 상품·링크를 자동 생성하지 않고 `affiliate_link_manifest`에 운영자가 확인한 링크만 넣는다.
- 각 글의 도입부 또는 링크가 처음 나타나는 위치에 고지문을 넣는다.
- 기본 고지문: `이 포스팅은 쿠팡 파트너스 활동의 일환으로 이에 따른 일정액의 수수료를 제공받습니다.`
- 제품의 가격, 재고, 할인, 효과, 순위는 발행 직전에 근거 URL과 확인 시각이 있어야 한다.
- 본인·동거 가족 구매 유도, 허위 사용후기, 근거 없는 비교·효능 표현은 금지한다.

## 발행 게이트

`ready_to_publish`는 아래 모두 충족 시에만 true다.

```text
experience_evidence_ok
AND photo_rights_ok
AND factual_claims_ok
AND affiliate_disclosure_ok (제휴 글일 때)
AND affiliate_links_verified (제휴 글일 때)
AND operator_approved
```

네이버 블로그 공개 발행은 외부 표현 행위이므로 운영자 승인 후 수행한다. 자동화의 기본 목표는 임시저장과 검수 완료다.

## Aside에 맡길 일

- 매일: 트렌드 후보 리포트 작성, 네이버 블로그 임시저장 화면 준비, 게시 결과 캡처 기록.
- 주간: 사진 폴더 메타데이터 누락 점검, 미발행 초안 리마인드.
- 맡기지 않을 일: 비밀번호 입력, 제휴 계정 가입, 쿠팡 링크 무단 생성, 승인 없는 공개 발행.
