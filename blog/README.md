# 블로그 자동화 모듈

> **운영 기준 변경 (2026-11-11):** 실제 경험, 원고, 승인, 작업 상태의 원본은 Notion `콘텐츠 운영 허브`의 DB 한 행이다. 이 폴더는 코드·예시·연동 규칙만 보관한다. 실제 콘텐츠를 이 폴더에 새로 만들지 않는다. [NOTION-OPERATING-HUB.md](NOTION-OPERATING-HUB.md)를 먼저 읽는다.

이 모듈은 2030 여성 독자를 위한 네이버 블로그 글을 기획하고, 사진을 선별·배치하고, 초안을 만들고, 검수 대기 상태까지 준비한다.

## 원칙

- AI는 사용자가 제공한 경험 메모와 승인된 사진만 `내 경험`으로 서술한다.
- 없는 사용 경험, 구매 사실, 제품 효과, 가격·할인 정보는 만들지 않는다.
- 제휴 링크가 있는 글은 광고표시, 링크 근거, 상품 검수, 운영자 최종 발행 승인이 모두 있어야 한다.
- 개인 사진은 `assets/personal/`에만 두며 Git·외부 프롬프트·공개 저장소에 올리지 않는다.
- AI 생성 이미지는 파일 메타데이터와 본문 자산 목록에 `ai_generated: true`로 기록한다.

## 단계

1. `topics/`에서 네이버 트렌드와 콘텐츠 주제 후보를 수집한다.
2. `briefs/`의 경험 브리프와 `assets/`의 사진 메타데이터를 읽어 주제를 고른다.
3. `drafts/`에 본문·사진 배치·출처·광고표시를 포함한 초안을 만든다.
4. `reviews/`에서 사실성·사진 권리·광고표시·제휴 링크를 검수한다.
5. 운영자 승인 후에만 네이버 블로그 발행 화면 또는 승인된 게시 수단으로 넘긴다.

상세 설계는 [PIPELINE-DESIGN.md](PIPELINE-DESIGN.md)를 따른다.
